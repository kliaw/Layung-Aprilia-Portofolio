# Layung Indra Aprilia — Portfolio Website

A responsive, single-file portfolio website built from the supplied profile.

## Preview
Open `index.html` in a modern browser.

## Included
- Responsive layout with sticky navigation and mobile menu
- About, experience timeline, skills, featured projects, QA documentation, resume, education, and contact sections
- Expandable role details
- Illustrative fictional test cases and bug reports
- Accessible focus styles, reduced-motion support, semantic landmarks, and SEO metadata
- Embeds the supplied CV PDF in `index.html` so view, download, and preview work in isolated previews as well as static hosting; the separate PDF is also included in the ZIP

## Customize
- Edit `index.html` to update content, colors, project cards, and contact details.
- The CV is embedded in `index.html`, so the buttons and preview do not depend on a relative PDF path. The separate `Layung_Aprilia_CV.pdf` is included for convenience.
- Add only sanitized, approved project artifacts; do not publish confidential client or employer information.

No external libraries or build step are required.


The CV download button embeds the PDF in `index.html` so it does not depend on a relative file path in preview environments. The separate `Layung_Aprilia_CV.pdf` is included as a standalone copy.
