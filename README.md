# Layung Indra Aprilia — Portfolio Website

Responsive single-file portfolio website.

## Preview
Open `index.html` in a modern browser.

## Included
- Responsive layout, sticky navigation, and mobile menu
- About, experience timeline, skills, featured projects, QA documentation, resume, education, and contact
- Expandable experience details and fictional QA examples
- Accessible focus styles, reduced-motion support, semantic landmarks, and SEO metadata
- Resume download intentionally unconfigured until the actual file or URL is supplied

## Customize
Edit `index.html` to update content, colors, project cards, and contact details. Add only approved, sanitized project artifacts. To embed a resume, add the real PDF and update the Resume section with a PDF viewer and a download link to that file.
